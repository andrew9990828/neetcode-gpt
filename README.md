# Machine Learning From Scratch

This repo is me working through the NeetCode ML course and getting better at turning ML concepts into code.

The goal is simple:
- understand the idea
- write the code myself
- get more comfortable with NumPy and PyTorch
- build up from the basics to neural networks, attention, transformers, and GPT

This repo is mainly for reps and learning.

## Topics

- Gradient descent
- Activation functions
- Loss functions
- Neural networks
- Backpropagation
- PyTorch
- Embeddings
- Attention
- Transformers
- GPT
